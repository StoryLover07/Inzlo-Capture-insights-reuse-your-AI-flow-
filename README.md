# Inzlo 🚀
> **Capture insights, reuse your AI flow.**

Inzlo is a powerful Chrome Extension designed to help you capture, organize, and reuse valuable insights from your interactions with AI models like ChatGPT. Built with efficiency in mind, it allows you to build a personal library of prompts and AI responses effortlessly.

## ✨ Features

- **Instant Capture:** Select any text on the web and save it directly to your Inzlo library with a single click.
- **Smart Organization:** View and manage your saved prompts in a sleek, minimalist popup.
- **Seamless Integration:** Built using the [Plasmo Framework](https://www.plasmo.com/), ensuring a fast and reliable experience across Chromium-based browsers.
- **Developer Friendly:** Clean TypeScript codebase with a React-powered UI.

## 🛠 Tech Stack

- **Framework:** [Plasmo](https://docs.plasmo.com/)
- **UI Library:** [React](https://reactjs.org/)
- **Language:** [TypeScript](https://www.typescriptlang.org/)
- **State Management:** Chrome Storage API

## 🚀 Getting Started

### Prerequisites

- Node.js (v18+)
- pnpm or npm

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/StoryLover07/Inzlo-Capture-insights-reuse-your-AI-flow-.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Inzlo
   ```
3. Install dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```

### Loading the Extension

1. Open Chrome and navigate to `chrome://extensions`.
2. Enable **Developer mode** (top right).
3. Click **Load unpacked** and select the `build/chrome-mv3-dev` folder.
