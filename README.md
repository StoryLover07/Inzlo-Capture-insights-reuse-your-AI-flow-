# 🚀 Inzlo — Capture Insights, Reuse Your AI Flow

Inzlo is a lightweight browser extension that transforms temporary text into reusable knowledge.

Instead of losing valuable prompts, phrases, or ideas, Inzlo lets you capture, organize, and reuse them instantly.

---

## 🧠 Why Inzlo?

When using AI tools or browsing the web, you often discover useful:

- GPT prompts
- Email templates
- Code snippets
- Structured instructions

But…

- Clipboard is temporary  
- Notes are slow to write  
- Content gets lost  

👉 You end up rewriting the same things again.

---

## 💡 Solution

Inzlo turns text into reusable assets.

> Not just saving — but making text reusable in context.

---

## ✨ Features

### 📌 Phase 1 (MVP)
- Select any text → Save button appears
- Store text instantly using Chrome extension
- View saved prompts in popup UI
- Click to copy
- Multi-select + delete
- “Copied!” feedback

---

### ⚡ Phase 2 (Usability)
- 🔍 Search prompts instantly
- 🏷️ Tag system (AI / Email / Code / etc.)
- 🎯 Filter by tag
- ⚡ Faster interaction (click-to-copy UX)

---

### 🧠 Phase 3 (Context-Aware — Coming Soon)
- Detect current website
- Show relevant prompts automatically

Examples:
- ChatGPT → AI prompts
- Gmail → email templates
- Code editor → dev snippets

---

## 🧩 How It Works

1. Select text on any webpage  
2. Click **Save**  
3. Assign a tag  
4. Open extension popup  
5. Click → instantly reuse  

---
